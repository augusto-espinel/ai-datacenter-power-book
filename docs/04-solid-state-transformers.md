# Chapter 4 — Solid-State Transformers (SST)

> 🚧 **Status:** Architecture placeholder — content to be populated.

## Overview

Solid-State Transformers replace conventional 60Hz iron-core transformers with high-frequency power electronics, enabling bidirectional power flow, voltage regulation, and galvanic isolation in a fraction of the volume.

## Key Concepts (To Be Developed)

- **DAB (Dual Active Bridge)** topology — the workhorse SST architecture
- LLC resonant converters for higher efficiency at fixed load
- SiC (Silicon Carbide) and GaN (Gallium Nitride) device characteristics
- ZVS (Zero Voltage Switching) and ZCS (Zero Current Switching) regions
- Bidirectional power flow and DC microgrid integration
- Comparison with conventional transformers: efficiency, volume, weight, cost
